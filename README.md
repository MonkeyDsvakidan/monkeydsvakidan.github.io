# GameMaster

Startseite der Spiel-App GameMaster: https://monkeydsvakidan.github.io/

Von hier geht es zu Music 1v1 und Musik-Quiz (Repo MusicBattle), TotalGuesser (Repo TotalGuesser), Poker (Repo PokerFriends) und den Spotify-Tools. Die Seite liefert ausserdem das gemeinsame App-Symbol und das Manifest, damit alles auf dem Handy eine App ist.

Auf dem iPhone: Seite in Safari öffnen → Teilen → «Zum Home-Bildschirm».

Details für die Arbeit am Code: `CLAUDE.md`.

Ein neues Spiel einbauen (Kachel + Leiste in allen Spielen): Checkliste in `CLAUDE.md`, Abschnitt «Neues Spiel in GameMaster einbauen».
